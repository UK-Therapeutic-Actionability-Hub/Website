# UK Therapeutic Actionability Hub

A minimal static website for the UK Therapeutic Actionability Hub.

## Files

- `index.html` — landing page
- `about.html` — about page
- `team.html` — coordinators and partners
- `contact.html` — contact and case submission page
- `css/style.css` — shared styles
- `images/partners/` — place partner logos here

## Before launch

Replace the placeholders in the HTML files with:

1. The two coordinator names and affiliations.
2. Partner organisation names.
3. Partner logo files in `images/partners/`.
4. The real contact email address.
5. The real case submission URL for both "Submit your case" buttons.
6. The final wording for the About page and case eligibility section.
